Problemática

Los estudiantes suelen tener dificultades para organizar sus actividades escolares, recordar las tareas pendientes y llevar un control de sus fechas de entrega. Esto puede provocar olvidos, retrasos y una mala administración del tiempo.

Por ello, se propone desarrollar un Sistema de Gestión de Tareas Escolares, que permita a los estudiantes registrar nuevas tareas, consultar las actividades pendientes, marcar tareas como completadas, eliminar tareas y consultar sus fechas de entrega.

El objetivo es ofrecer una herramienta sencilla que facilite la organización y el seguimiento de las responsabilidades académicas.

Acuerdos de trabajo

Como equipo, establecemos los siguientes acuerdos para mantener una buena organización durante el desarrollo del proyecto:

1. Comunicación constante: Todos los integrantes mantendremos comunicación para compartir avances, resolver dudas y reportar cualquier problema relacionado con el proyecto.
2. Responsabilidad y colaboración: Cada integrante cumplirá con las actividades que le sean asignadas y apoyará a los demás cuando sea necesario para alcanzar los objetivos del equipo.
3. Trabajo organizado y control de cambios: Utilizaremos GitHub para compartir el código, registrar los avances y revisar los cambios antes de integrarlos al proyecto, evitando modificaciones que puedan afectar el funcionamiento del sistema.

## Definición de Terminado (DoD)

Una tarea o historia se considera terminada cuando cumple con los siguientes criterios:

1. El desarrollo de la funcionalidad está completo.
2. El código cumple con los requisitos establecidos.
3. Se realizaron las pruebas correspondientes.
4. Las pruebas se ejecutaron correctamente.
5. Se revisaron los cambios antes de integrarlos.
6. No existen errores conocidos que impidan el funcionamiento.

8. La documentación correspondiente fue actualizada cuando fue necesario.

## Funcionalidades del sistema

El Sistema de Gestión de Tareas Escolares permite organizar y administrar las actividades académicas de los estudiantes de una manera sencilla.

Entre sus principales funcionalidades se encuentran:

- **Registro de tareas:** permite agregar nuevas actividades escolares con su título, descripción y fecha de entrega.
- **Consulta de tareas:** permite visualizar las tareas registradas para mantener un mejor control de las actividades.
- **Organización de actividades:** facilita la identificación de las tareas pendientes y las que ya fueron realizadas.
- **Actualización de tareas:** permite modificar la información de las actividades cuando sea necesario.
- **Seguimiento académico:** ayuda a los estudiantes a llevar un control de sus responsabilidades escolares.

## Objetivo del proyecto

Desarrollar un sistema que facilite la organización y el seguimiento de las tareas escolares, ayudando a los estudiantes a administrar mejor sus actividades y fechas de entrega.
